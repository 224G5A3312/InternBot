# InternBot

InternBot is an AI-powered internship FAQ assistant that helps students and fresh graduates get quick and accurate answers to common internship-related questions. The system uses Natural Language Processing (NLP) to understand user queries and provide relevant responses efficiently. It is built with Python and Flask, ensuring smooth backend processing and easy scalability. InternBot leverages TF-IDF and cosine similarity algorithms to match user questions with the most appropriate answers from a predefined FAQ dataset. The project includes an interactive interface for real-time communication, making it simple and user-friendly. It reduces repetitive queries for HR teams while improving access to important internship information. The architecture is lightweight yet effective, allowing future enhancements such as web-based interfaces or API integration. Overall, InternBot provides a smart and scalable solution for automating internship-related support.
